# Optional Profile Features

These additions are intentionally not enabled in the main README. Add them only when they improve the profile.

## Dynamic GitHub statistics

Paste this section above `## Current focus`:

```html
## GitHub activity

<div align="center">
  <img height="165" src="https://github-readme-stats.vercel.app/api?username=DigiArkTech&show_icons=true&hide_border=true&rank_icon=github&theme=transparent" alt="DigiArkTech GitHub statistics">
  <img height="165" src="https://github-readme-stats.vercel.app/api/top-langs/?username=DigiArkTech&layout=compact&hide_border=true&theme=transparent" alt="Most used public repository languages">
</div>
```

Important: these cards use a third-party service and primarily reflect public repository data. They can temporarily fail or create a misleading impression when most work is private.

## Animated typing line

This can be placed below the banner:

```html
<div align="center">
  <img src="https://readme-typing-svg.demolab.com?font=Inter&weight=600&size=22&pause=1200&color=2563EB&center=true&vCenter=true&width=900&lines=Building+practical+software+for+real+business+workflows;Product+thinking+%2B+systems+%2B+implementation;Automation%2C+e-commerce%2C+travel+technology%2C+and+operations" alt="Animated introduction">
</div>
```

This is visually engaging but less restrained than the default profile.

## Native clickable disclosure

The supplied README already uses GitHub's supported `<details>` and `<summary>` pattern. It is the closest native equivalent to an interactive presentation panel.

## True hover effects

A GitHub README is not a freely programmable web page. Do not rely on JavaScript, embedded applications, or custom CSS hover effects. Create a portfolio website later when full interactivity is important.
